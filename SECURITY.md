# Security policy

Bluewater Haul v0.7 is an early single-player prototype. There is no online
service, account system or telemetry in the supplied source.

For security concerns involving local file handling or dependency problems,
please report the issue privately using GitHub's **Report a vulnerability**
feature if it is enabled on the repository. Otherwise contact the repository
maintainer using a private channel listed on their GitHub profile; do not post
exploit payloads or private saved games in a public issue.

There is currently no guaranteed response window or formal support period.
Avoid running downloaded executables from unofficial sources and verify release
assets through the repository's own GitHub releases.
