# Bluewater Haul v0.7.0 — Sarnia prototype

An original Canadian neighbourhood/trucking RPG vertical slice built with
C#, .NET 8 and MonoGame. Drive deliveries through an OSM-derived Sarnia,
explore on foot, enter generated buildings, try several vehicles, navigate
mapped streets, encounter ambient traffic and witnesses, and experience
simplified collisions and police response.

### Download and play

Download the **`BluewaterHaul-v0.7.0-win-x64.zip`** asset from this GitHub
release, extract it completely and run **`BluewaterHaul.exe`**. This is a
self-contained Windows x64 build (OpenGL-capable graphics drivers required).
The auto-generated "Source code" archives are for developers only.

Press **F1** to dismiss the introduction, **M** to open the map, **E** to
interact, and **W/A/S/D** to drive or walk. Your first delivery is loaded.

### Read before playing

- Early prototype: not an accurate truck simulator, GPS or city replica.
- Buildings, interiors, people and much of the street furniture are generated.
- Map data © OpenStreetMap contributors (ODbL 1.0); original code MIT.
- See `README.md`, `THIRD_PARTY_NOTICES.md` and the source repository for docs.

### Known limitations

- Actual Windows playtesting is recommended before calling this release stable.
- One-way and street routing are approximate; some footpaths are missing.
- No functional US border crossing; detailed interiors and traffic are fictional.
- Suspension, full economic systems and long-form quests are out of scope.
